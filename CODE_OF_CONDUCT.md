# Code of conduct

Archive 115 adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. It applies to the repository (issues, pull requests, reviews, discussions) and to anyone representing the project elsewhere.

In short:

- Be welcoming to people of every background and level of experience, including first-time contributors and people writing in their second language.
- Criticise work, not people. Assume good faith and explain the "why" in reviews.
- No harassment, insults, sexualised language or imagery, or publishing other people's private information.
- Keep spoilers out of issue titles and summaries; others read them before deciding to look.

## Reporting

Report anything that breaks these rules **privately, through GitHub**:

- On the offending comment, issue or pull request, open the **⋯** menu and choose **Report content**, then **Report to repository admins**. Only the maintainers see it.
- If it is serious (threats, doxxing, spam campaigns), also report it to GitHub with **Report to GitHub support**.

Maintainers will review every report, keep the reporter's identity private and respond with the measures described in the Contributor Covenant's [enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines): a private warning, a temporary ban or a permanent ban, depending on the case.
